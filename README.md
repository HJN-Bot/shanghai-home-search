# 上海购房搜索（Shanghai Home Search）

Jianan 的上海买房长期任务仓库，由 Jimmy 维护。

## 硬条件
- 开价：800–900 万，800 多最好（成本控制要硬）
- 面积：约 130–140㎡
- 房龄：2015 年前后及之后竣工
- 环境好（小区品质、绿化、配套）
- 范围：浦西、浦东都看；也看比大华更靠市中心一点的板块

## 目录
- `data/communities.csv`：候选小区池（板块、竣工年份、均价、坐标、来源）
- `data/listings.csv`：在售房源记录（平台、链接、价格、面积、户型、楼层、挂牌日期、抓取日期）
- `map/`：板块地图（标注候选小区和房源）
- `notes/`：看房记录、板块分析
