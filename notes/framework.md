## 4. 判断标准（后来接手的 agent 按这个来）

1. **只报核实过的房源**：价格/面积/户型/房龄/地址/链接六项缺一不可；没有链接的不要编链接，没有核实的不写进短名单。
2. **房龄以小区竣工年份为准**，不是挂牌文案里的“次新房”说法；两个来源打架时取更保守的（更早的）年份并标注。
3. **面积超/欠 5㎡ 以内可以列入**，但必须在“状态”里标注；超 5㎡ 或总价超 ¥900 万的直接排除，进“已排除”清单。
4. **三房永远是备选**，不能和四房混在同一个主表里排序；主表只排四房。
5. **新房（开发商直售）单独放一节**，不要和二手房混表；总价写“起价/备案均价”，注明以案场一房一价为准。
6. 每次更新：改 `listings.md` 明细 + 本文件总表 + 更新日期；房源下架/涨价/降价都要留一条变更记录（见 `listings.md` 末尾）。
